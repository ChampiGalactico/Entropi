## Why Entropi exists

Entropi began as a personal project for my own day-to-day university life, and it is also my first desktop application. I wanted one place where my classes, assignments, exams, grades, notes, professors, and personal plans could actually live together.

University does not leave much free time, and the tools I found either split everything across several applications or required moving personal academic data to the cloud. I built Entropi for myself, but I realized that other students might be looking for the same kind of workspace: practical, flexible, private, and designed around how university life really works.

Entropi is still evolving. It is already useful, but you should expect active development and the occasional rough edge. Feedback and contributions are welcome.

## Features

- **Calendar views** — Monthly, weekly, and daily views for classes, evaluations, assignments, and personal events.
- **Subject management** — Organize subjects by semester, with reusable schedules, session types, locations, professors, complementary instructors, and monitors.
- **Unified tasks** — Keep academic work and everyday tasks in the same system without forcing every task to belong to a subject.
- **Evaluations and grades** — Model weighted grading structures, record individual grades, and keep calculations precise without hidden rounding.
- **Weekly planning** — Prepare classes, establish weekly objectives, and close the week with a reflection.
- **Rich notes** — Write with BlockNote, render inline and block LaTeX, insert drawings, and relate notes to subjects, assignments, or evaluations.
- **Learning topics** — Save low-pressure topics for the moments when you have time and curiosity to explore them.
- **Professor directory** — Keep contact information, office details, and the small notes that make future interactions easier.
- **Custom reference data** — Adapt session types, assessment types, task types, roles, locations, and other reference tables to your university.
- **Optional automatic startup** — Choose whether Entropi opens when you sign in to your computer.
- **Local-first storage** — Entropi uses a local SQLite database. No account or cloud connection is required.

## Download

Installers are published on the [GitHub Releases page](https://github.com/ChampiGalactico/Entropi/releases).

| Platform | Available packages |
| --- | --- |
| Windows | NSIS `.exe` and MSI `.msi` installers |
| macOS — Apple Silicon | ARM64 `.dmg` |
| macOS — Intel | x64 `.dmg` |
| Linux | AppImage, Debian package, and other bundles generated by Tauri |

On first launch, Entropi creates its local database automatically. No database setup is required.

> [!WARNING]
> Entropi is not code-signed or notarized yet. Windows and macOS may display a security warning, and recent macOS versions may block the first launch. Review the release and source before deciding whether to proceed. Officially frictionless macOS distribution will require Apple code signing and notarization.

## Technology

- [Tauri v2](https://tauri.app/) for the native desktop shell
- [React](https://react.dev/) and [TypeScript](https://www.typescriptlang.org/) for the interface
- [Vite](https://vite.dev/) for frontend tooling
- [Tailwind CSS](https://tailwindcss.com/) for styling
- [Zustand](https://github.com/pmndrs/zustand) for client state
- [SQLite](https://www.sqlite.org/) through `@tauri-apps/plugin-sql` for local persistence
- [BlockNote](https://www.blocknotejs.org/) for rich-text notes
- [MathJax](https://www.mathjax.org/) for mathematical notation
- [Solar Icons](https://solar-icons.vercel.app/) for the icon system

## Development

### Requirements

- [Node.js](https://nodejs.org/) 24 or newer
- [Rust](https://www.rust-lang.org/tools/install)
- The [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your operating system

### Run the desktop application

```bash
git clone https://github.com/ChampiGalactico/Entropi.git
cd Entropi
npm ci
npm run tauri dev
```

Use `npm run tauri dev` when testing database operations or native functionality. To work only on the browser interface, run `npm run dev` and open `http://localhost:1420`.

### Build locally

```bash
npm run tauri build
```

Tauri places the generated packages under `src-tauri/target/release/bundle/`.

## Publishing a release

The release workflow builds Entropi for Windows, Linux, macOS Apple Silicon, and macOS Intel. Before publishing, keep the application version synchronized in:

- `package.json`
- `src-tauri/tauri.conf.json`
- `src-tauri/Cargo.toml`

Create and push a matching semantic version tag:

```bash
git tag -a v0.1.0 -m "Entropi v0.1.0"
git push origin v0.1.0
```

GitHub Actions will compile each platform and publish a release containing the generated installers. Because the builds run on different operating systems, their assets can appear gradually while the workflow is still running.

## Contributing

Contributions, bug reports, and ideas are welcome.

1. Fork the repository.
2. Create a focused branch: `git checkout -b feature/my-change`.
3. Commit the change with a clear message.
4. Push the branch to your fork.
5. Open a pull request explaining the problem and the proposed solution.

Please avoid committing personal databases, credentials, or university data.
